# Bundled Kvantum Qt 6 engine source

KDE neon User Edition currently uses an Ubuntu Noble base whose official
repositories provide only the Qt 5 Kvantum engine. The installer builds this
source release only when a Debian-family host has no distro-owned Qt 6 style
plugin. It never adds a PPA and never downloads Kvantum during installation.
